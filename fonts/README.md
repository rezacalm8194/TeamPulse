# Vazirmatn

Unmodified static WOFF2 files from the official [v33.003 release](https://github.com/rastikerdar/vazirmatn/releases/tag/v33.003):

- `fonts/webfonts/Vazirmatn-Regular.woff2` (400)
- `fonts/webfonts/Vazirmatn-SemiBold.woff2` (600)

Source files: https://github.com/rastikerdar/vazirmatn/tree/v33.003/fonts/webfonts

Copyright and SIL Open Font License are preserved in `OFL.txt`.
Only these two weights are hosted; heavier CSS weights use browser synthesis.
